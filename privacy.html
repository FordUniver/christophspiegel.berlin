Datenschutzerklärung / Privacy Policy

Datenschutzerklärung (Deutsch)

1. Verantwortlicher

Der Verantwortliche im Sinne der DSGVO ist die im Impressum genannte Person.

2. Art der Datenerhebung

Bei jedem Aufruf dieser Webseite erfasst der Webserver automatisch technische Zugriffsdaten, darunter IP-Adresse, aufgerufene Dateien, Datum und Uhrzeit des Zugriffs sowie Browserinformationen. Diese Daten werden von unserem Hosting-Anbieter verarbeitet (siehe Abschnitt 3).

3. Hosting

Diese Website wird über GitHub Pages gehostet, einem Dienst der GitHub, Inc. (Microsoft-Tochtergesellschaft), 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Bei jedem Seitenaufruf verarbeitet GitHub folgende Daten aus Ihrem Browser in sog. Logfiles: IP-Adresse, die Adresse der vorher besuchten Website (Referer Anfrage-Header), Datum und Uhrzeit der Anfrage sowie Informationen zu Browser und Betriebssystem. Dies ist erforderlich, um diese Website anzuzeigen und die Stabilität und Sicherheit zu gewährleisten. Die Verarbeitung erfolgt auf Grundlage unseres berechtigten Interesses im Sinne des Art. 6 Abs. 1 S. 1 lit. f DSGVO. Da GitHub, Inc. in den USA ansässig ist, werden Daten in die USA übertragen; GitHub hat hierfür Standardvertragsklauseln (SCC) gemäß Art. 46 Abs. 2 lit. c DSGVO abgeschlossen. Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub.

4. Web-Analyse mit Plausible Analytics

Diese Website nutzt Plausible Analytics auf einer eigenen Instanz des Zuse-Instituts Berlin (plausible.iol.zib.de). Das lokal bereitgestellte Analyseskript übermittelt Seitenaufrufe, die besuchte URL und gegebenenfalls die verweisende Website an diese Instanz. Dabei werden technisch auch die IP-Adresse und die Browserkennung übertragen. Der Tracker setzt keine Analyse-Cookies und speichert keine Besucherkennung im Browser.

Die Auswertung dient der aggregierten Nutzungsstatistik, etwa zu Seitenaufrufen, Zugriffsquellen, Browsern und Ländern. Rechtsgrundlage ist unser berechtigtes Interesse an der Verbesserung dieser Website gemäß Art. 6 Abs. 1 S. 1 lit. f DSGVO. Die Dokumentation von Plausible erläutert die Verarbeitung durch die Analysesoftware. Informationen zum Datenschutz beim Betreiber finden Sie unter zib.de/impressum; dessen Datenschutzbeauftragter ist unter dsb@zib.de erreichbar.

5. Lokale Dateien und Darstellungseinstellungen

Schriftarten, Bilder, Stylesheets und JavaScript-Dateien werden mit dieser Website ausgeliefert. Es werden keine Dateien von Google Fonts oder öffentlichen Skript-CDNs nachgeladen. Die oben beschriebene Analyse sendet Daten an die ZIB-Instanz.

Wenn Sie eine helle oder dunkle Darstellung auswählen, wird ausschließlich diese Einstellung unter homepage-theme im lokalen Speicher Ihres Browsers gespeichert. Sie wird nicht an den Server übertragen und bleibt bis zum Löschen des Browserspeichers oder der Auswahl von „Auto“ erhalten. Ohne eigene Auswahl folgt die Darstellung Ihrer Systemeinstellung.

6. Ihre Rechte

Sie haben gegenüber uns folgende Rechte hinsichtlich der Sie betreffenden personenbezogenen Daten: (1) Recht auf Auskunft, (2) Recht auf Berichtigung oder Löschung, (3) Recht auf Einschränkung der Verarbeitung, (4) Recht auf Widerspruch gegen die Verarbeitung, (5) Recht auf Datenübertragbarkeit.

Sie haben außerdem das Recht, sich bei einer Datenschutz-Aufsichtsbehörde über die Verarbeitung Ihrer personenbezogenen Daten zu beschweren.

Privacy Policy (English)

1. Data Controller

The data controller within the meaning of the GDPR is the person named in the legal notice.

2. Type of Data Collection

Each time this website is accessed, the web server automatically collects technical access data, including IP address, requested files, date and time of access, and browser information. This data is processed by our hosting provider (see Section 3).

3. Hosting

This website is hosted via GitHub Pages, a service of GitHub, Inc. (a Microsoft subsidiary), 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Each time the site is accessed, GitHub processes the following data transmitted by your browser in log files: IP address, address of the previously visited website (referrer request header), date and time of the request, and information about browser and operating system. This is necessary to display this website and to ensure stability and security. Processing is based on our legitimate interest within the meaning of Art. 6 para. 1 sentence 1 lit. f GDPR. As GitHub, Inc. is based in the USA, data is transferred to the United States; GitHub has concluded Standard Contractual Clauses (SCCs) pursuant to Art. 46 para. 2 lit. c GDPR to ensure an adequate level of data protection. For more information, see GitHub’s privacy statement.

4. Web Analytics with Plausible Analytics

This website uses Plausible Analytics on a dedicated Zuse Institute Berlin instance (plausible.iol.zib.de). The locally served analytics script sends page views, the visited URL, and any referring website to that instance. These requests also transmit the IP address and browser identification as part of the connection. The tracker sets no analytics cookies and stores no visitor identifier in the browser.

The analysis provides aggregate usage statistics, including page views, referral sources, browsers, and countries. Processing is based on our legitimate interest in improving this website under Article 6(1)(f) GDPR. The Plausible documentation explains the analytics software’s processing. For information about the operator’s data protection practices, see zib.de/impressum; its data protection officer can be contacted at dsb@zib.de.

5. Local Assets and Display Preferences

Fonts, images, stylesheets, and JavaScript files are served with this website. No files are loaded from Google Fonts or public script CDNs. The analytics described above sends data to the ZIB instance.

If you select a light or dark theme, only that preference is saved under homepage-theme in your browser’s local storage. It is not sent to the server and remains until you clear browser storage or select “Auto”. Without an explicit choice, the website follows your system preference.

6. Your Rights

You have the following rights with regard to personal data concerning you: (1) right of access, (2) right to rectification or erasure, (3) right to restriction of processing, (4) right to object to processing, (5) right to data portability.

You also have the right to lodge a complaint with a data protection supervisory authority regarding the processing of your personal data.
