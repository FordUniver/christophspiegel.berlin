AI4Forest

MATH+ Excellence Cluster EF1-21

Scaling up Flag Algebras in Combinatorics

Scales Razborov's flag algebras through symmetry reduction and extends them to new settings such as Rado multiplicity in vector spaces.

MATH+ Excellence Cluster EF1-12

Learning Extremal Structures in Combinatorics

MATH+ Excellence Cluster EF1-9

Adaptive Algorithms through Machine Learning

Uses machine learning to adapt branch-and-cut solvers at run time, learning cut selection, branching, and heuristic scheduling.
